# ADR 0009: The project is named Gauja

| Field | Value |
|---|---|
| Status | Accepted |
| Date | 2026-09-05 |
| Governing PRD section | [`docs/gauja-prd.md` §1](../gauja-prd.md#1-summary) |

## Context

The app needs a name that is not Seerr's, does not use Seerr's marks, is short, pronounceable in the project's languages and free as an app-store and package identifier.

## Decision

The project, both apps and the repository are named **Gauja**. Store listings describe it as an unofficial companion to Seerr; "Seerr" appears descriptively only.

## Consequences

- Package identifiers, bundle identifiers and the repository name derive from "Gauja".
- The unaffiliated statement appears in `README.md` and every store listing.
